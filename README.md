# 🤖 بوت تيليجرام المتكامل لإدارة وإرسال الرسائل (Telegram Broadcast & Control Panel Bot)

مشروع احترافي متكامل مبني بلغة **Python** بالاعتماد على **aiogram 3.x** و **SQLAlchemy 2.0 (AsyncIO)** و **APScheduler**، يوفر لوحة تحكم باللغة العربية لإدارة الأهداف (قنوات ومجموعات)، إنشاء حملات إرسال فورية أو مجدولة، دعم كافة أنواع الوسائط، تكرار بفواصل زمنية، فحص الصلاحيات، وحماية متقدمة من قيود تيليجرام مع تصدير تقارير CSV.

---

## 🌟 الميزات الرئيسية

1. **المصادقة والتعددية (Multi-User Isolation)**:
   - البوت متاح للجميع للاستخدام، ولكل مستخدم أهدافه وحملاته وتقاريره المعزولة في قاعدة البيانات.
   - دعم رتبة **مشرف عام (Super Admin)** مع لوحة إحصائيات شاملة للنظام.

2. **لوحة تحكم تفاعلية (Inline Dashboard)**:
   - واجهة باللغة العربية بالكامل وبأزرار شاشة تفاعلية Inline بدون أوامر نصية معقدة.
   - أقسام: إرسال، إدارة الأهداف، حالة البوت، التقارير والإحصائيات، الإعدادات.

3. **إدارة متقدمة للأهداف**:
   - إضافة القنوات والمجموعات بواسطة المعرف الرقمي `chat_id` أو اسم المستخدم `@username` أو الرابط المباشر.
   - **فحص فوري وتلقائي للصلاحيات**: التحقق مما إذا كان البوت مضافًا، وهل يملك صلاحية `can_post_messages` أو إرسال الوسائط.
   - تنبيه فوري باللون الأصفر ⚠️ إذا كان البوت مقيدًا أو تنقصه رتبة الإشراف.
   - إمكانية تحديث صلاحيات كافة الأهداف بضغطة زر واحدة.

4. **محرك إرسال مرن وشامل**:
   - دعم إرسال: **نص عادي (مع التنسيقات HTML/Markdown)**، **صورة مع كابشن**، **فيديو مع كابشن**، **مستند/ملف مع كابشن**.
   - قائمة اختيار تفاعلية بالأهداف مع إمكانية التحديد الفردي، "تحديد الكل"، أو "إلغاء التحديد".
   - **تكرار الرسائل**: خيارات جاهزة (1، 3، 5، 10 مرات) أو إدخال عدد مخصص.
   - **فاصل زمني بين دورات التكرار**: إمكانية الانتظار دقائق أو ساعات بين كل دورة إرسال.
   - **التحكم بسرعة الإرسال (Rate Limiting)**: تحديد الفاصل الزمني بالثواني بين كل هدف والآخر لتجنب الحظر والسبام.
   - **الجدولة الدقيقة (APScheduler)**: دعم إطلاق الحملة فورًا، أو جدولتها لوقت محدد (اليوم/الغد أو تاريخ ووقت مستقبلي).

5. **الأمان وحماية التيليجرام**:
   - **منع التزامن المزدوج**: منع تشغيل أكثر من حملة لنفس الهدف في نفس الوقت من خلال نظام أقفال (Locks) دقيق.
   - **التعامل الذكي مع FloodWait**: التقاط استثناءات `TelegramRetryAfter` تلقائيًا والانتظار بالثواني المطلوبة ثم إعادة المحاولة وتسجيل مدة الانتظار.
   - تسجيل تفصيلي لكل حدث ورسالة في logs.

6. **التقارير وتصدير CSV**:
   - إحصائيات عامة مباشرة في الشاشة: إجمالي الرسائل الناجحة، الفاشلة، ونسبة النجاح.
   - **تصدير تقرير CSV شامل**: ملف منظم بترميز `utf-8-sig` (متوافق مع Excel باللغة العربية) يتضمن:
     - اسم الهدف ومعرفه الرقمي.
     - حالة الإرسال (نجاح/فشل).
     - سبب الفشل إن وجد.
     - مدة الانتظار (Retry After).
     - توقيت الإرسال بالتاريخ والوقت.

7. **قاعدة البيانات**:
   - مدعومة بـ SQLAlchemy 2.0 Async.
   - تعمل افتراضيًا على **SQLite** بدون أي إعدادات إضافية.
   - جاهزة للتبديل الفوري إلى **PostgreSQL** بمجرد تغيير سطر واحد في `.env`.

## 🚀 التثبيت والتشغيل (Quick Start)

### 1. المتطلبات:
- تثبيت Python 3.11 أو أحدث.

### 2. تجهيز البيئة الافتراضية:
```bash
# إنشاء البيئة الافتراضية
python -m venv venv

# تفعيل البيئة في ويندوز:
venv\Scripts\activate

# أو تفعيل البيئة في لينكس/ماك:
source venv/bin/activate
```

### 3. تثبيت المكتبات:
```bash
pip install -r requirements.txt
```

### 4. ضبط المتغيرات البيئية:
قم بإنشاء ملف باسم `.env` من خلال نسخ `.env.example`:
```bash
cp .env.example .env
```
افتح ملف `.env` وقم بملء البيانات:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz_SAMPLE_TOKEN
ADMIN_IDS=123456789
DATABASE_URL=sqlite+aiosqlite:///./bot_database.db
DEFAULT_TIMEZONE=Africa/Cairo
DEFAULT_DELAY_BETWEEN_TARGETS=1.5
```
> **ملاحظة:**
> - للحصول على `BOT_TOKEN`: راسل [@BotFather](https://t.me/BotFather) في تيليجرام وأنشئ بوت جديد.
> - للحصول على `ADMIN_IDS`: راسل [@userinfobot](https://t.me/userinfobot) للحصول على معرفك الرقمي.

### 5. تشغيل البوت:
```bash
python main.py
```

## 🗄 التبديل إلى PostgreSQL (اختياري)
إذا أردت استخدام PostgreSQL في بيئة الإنتاج:
1. تأكد من تشغيل خادم PostgreSQL وإنشاء قاعدة بيانات باسم `bot_db`.
2. في ملف `.env`، غيّر `DATABASE_URL` إلى:
```env
DATABASE_URL=postgresql+asyncpg://username:password@localhost:5432/bot_db
```
وسيقوم البوت تلقائيًا بإنشاء كافة الجداول وتهيئتها عند التشغيل الأول.

## 🛡 إرشادات هامة لتفادي حظر تيليجرام
1. اضبط فاصل زمني بين الأهداف لا يقل عن `1.0` إلى `2.0` ثانية (مضبوط افتراضيًا على 1.5 ثانية).
2. تأكد من رفع البوت كمشرف (Admin) في القنوات ومنحه صلاحية `نشر الرسائل` (Post Messages).
3. في حال حدوث `FloodWait`، يقوم البوت تلقائيًا بتهدئة الإرسال والنوم للمدة التي يحددها تيليجرام لحماية البوت من الحظر.
